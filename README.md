# 🟡 Блок 1. Действия над матрицами

## 6. Сложение матриц

Вычисли:

```text
A = | 2  3 |
    | 4  1 |

B = | 5  1 |
    | 2  6 |
```

Найди `A + B`.

<details>
<summary>Ответ</summary>

Складываем соответствующие элементы:

```text
A + B = | 2+5  3+1 |
        | 4+2  1+6 |

      = | 7  4 |
        | 6  7 |
```

</details>

---

## 7. Можно ли сложить матрицы?

Даны матрицы размеров:

```text
A — 2 × 3
B — 3 × 2
```

Определена ли операция `A + B`?

<details>
<summary>Ответ</summary>

Нет.

Сложение матриц возможно только для матриц <b>одинакового размера<b>.

```text
2 × 3 ≠ 3 × 2
```

Следовательно, `A + B` не определено.

</details>

---

## 8. Умножение матрицы на число

Вычисли:

```text
A = | 1  -2 |
    | 3   4 |

3A = ?
```

<details>
<summary>Ответ</summary>

Каждый элемент умножается на `3`:

```text
3A = |  3  -6 |
     |  9  12 |
```

</details>

<details>
<summary>Ответ</summary>

При транспонировании строки становятся столбцами:

```text
Aᵀ = | 1  4 |

     | 3  6 |
```

</details>

## 10. Элементарные преобразования

Какие операции относятся к элементарным преобразованиям матрицы?

<details>
<summary>Ответ</summary>

Три вида:

1. Перестановка двух параллельных рядов.
2. Умножение всех элементов ряда на ненулевое число.
3. Прибавление к одному ряду соответствующего другого ряда, умноженного на одно и то же число.

</details>

## 11. Проверка произведения матриц

Даны

```text
A — 2 × 3
B — 3 × 4
```

Каков размер матрицы `AB`?

<details>
<summary>Ответ</summary>

Внутренние размеры совпадают:

```text
(2 × 3)(3 × 4)
```

Следовательно, произведение определено, а результат имеет внешние размеры:

```text
AB — 2 × 4
```

</details>

## 12. Вычисление произведения

Вычисли:

```text
A = | 1  2 |
    | 3  4 |

B = | 5  6 |
    | 7  8 |
```

Найди `AB`.

<details>
<summary>Ответ</summary>

Каждый элемент получается как сумма произведений элементов строки первой матрицы и столбца второй:

```text
AB = | 1·5 + 2·7   1·6 + 2·8 |
     | 3·5 + 4·7   3·6 + 4·8 |

   = | 19  22 |
     | 43  50 |
```

</details>

## 13. Всегда ли `AB = BA`?

Для произвольных матриц верно ли равенство

```text
AB = BA
```

?

<details>
<summary>Ответ</summary>

Нет.

В общем случае умножение матриц <b>не является перестановочным<b>:

```text
AB ≠ BA
```

Матрицы, для которых `AB = BA`, называются <b>перестановочными<b>.

</details>

# 🟠 Блок 2. Определители

## 14. Определитель второго порядка

Вычисли:

```text
| 3  5 |
| 2  7 |
```

<details>
<summary>Ответ</summary>

Для определителя второго порядка:

```text
det A = a₁₁a₂₂ − a₁₂a₂₁
```

Поэтому:

```text
det A = 3·7 − 5·2
      = 21 − 10
      = 11
```

Ответ:

```text
11
```

</details>

---

## 15. Определитель второго порядка с отрицательными числами

Вычисли:

```text
| 2  -3 |
| 5   4 |
```

<details>
<summary>Ответ</summary>

```text
det A = 2·4 − (−3)·5
      = 8 + 15
      = 23
```

Ответ:

```text
23
```

</details>

## 16. Свойства определителей

Что произойдёт с определителем, если поменять местами две его параллельные строки?

<details>
<summary>Ответ</summary>

Определитель <b>изменит знак<b>.

Например:

```text
det A = 5
```

после перестановки двух строк:

```text

```

</details>

## 17. Одинаковые строки

Чему равен определитель, если две его строки одинаковы?

<details>
<summary>Ответ</summary>

Такой определитель равен:

```text
0
```

Это одно из основных свойств определителей.

</details>

## 18. Вынесение множителя

Что можно сделать, если все элементы одной строки определителя имеют общий множитель `k`?

<details>
<summary>Ответ</summary>

Общий множитель можно вынести за знак определителя.

Например:

```text
| 2a  2b |
|  c   d |
```

можно представить как

```text
2 · | a  b |
    | c  d |
```

</details>

## 19. Элементарное преобразование определителя

Определитель не изменяется, если к одной строке прибавить другую строку, умноженную на произвольное число.

Верно или неверно?

<details>
<summary>Ответ</summary>

<b>Верно.<b>

Например, преобразование

```text
R₂ → R₂ + 3R₁
```

не изменяет значение определителя.

</details>

## 20. Вычисли определитель 3-го порядка

Вычисли:

```text
| 1  2  3 |
| 0  4  5 |
| 1  0  2 |
```

<details>
<summary>Ответ</summary>

Разложим по первой строке:

```text
det A =
1·|4  5| − 2·|0  5| + 3·|0  4|
   |0  2|     |1  2|     |1  0|

= 1·(8 − 0)
  − 2·(0 − 5)
  + 3·(0 − 4)

= 8 + 10 − 12
= 6
```

Ответ:

```text
6
```

</details>

## 21. Минор элемента

Для матрицы

```text
A = | 1  2  3 |
    | 4  5  6 |
    | 7  8  9 |
```

найди минор элемента `a₁₂`.

<details>
<summary>Ответ</summary>

Для нахождения минора `M₁₂` вычёркиваем:

- 1-ю строку;
- 2-й столбец.

Получаем:

```text
| 4  6 |
| 7  9 |
```

Следовательно:

```text
M₁₂ = 4·9 − 6·7
     = 36 − 42
     = −6
```

</details>

## 22. Алгебраическое дополнение

Для предыдущей матрицы найди алгебраическое дополнение `A₁₂`.

<details>
<summary>Ответ</summary>

Используем:

```text
Aᵢⱼ = (−1)ⁱ⁺ʲ Mᵢⱼ
```

Для `i = 1`, `j = 2`:

```text
A₁₂ = (−1)³ M₁₂
     = −M₁₂
     = −(−6)
     = 6
```

Ответ:

```text
A₁₂ = 6
```

</details>

# 🔵 Блок 3. Невырожденные матрицы и ранг

## 23. Невырожденная матрица

Когда квадратная матрица называется невырожденной?

<details>
<summary>Ответ</summary>

Матрица называется <b>невырожденной<b>, если её определитель не равен нулю:

```text
det A ≠ 0
```

Если

```text
det A = 0
```

матрица называется вырожденной.

</details>

---

## 24. Определи, существует ли обратная матрица

Дана квадратная матрица `A`, причём:

```text
det A = −7
```

Существует ли у неё обратная матрица?

<details>
<summary>Ответ</summary>

Да.

Так как:

```text
det A = −7 ≠ 0
```

матрица невырожденная.

Поэтому обратная матрица существует.

</details>

---

## 25. Что означает `AA⁻¹ = E`?

Какой смысл имеет равенство

```text
AA⁻¹ = E
```

?

<details>
<summary>Ответ</summary>

`A⁻¹` — обратная матрица к `A`, а `E` — единичная матрица того же порядка.

Для обратной матрицы выполняется:

```text
A⁻¹A = AA⁻¹ = E
```

</details>

---

## 26. Найди обратную матрицу для 2 × 2

Дана матрица

```text
A = | 2  1 |
    | 1  1 |
```

Найди `A⁻¹`.

<details>
<summary>Ответ</summary>

Сначала:

```text
det A = 2·1 − 1·1 = 1
```

Для матрицы 2 × 2:

```text
A⁻¹ = 1/det A · |  d  −b |
                  | −c   a |
```

Получаем:

```text
A⁻¹ = |  1  −1 |
      | −1   2 |
```

Проверка:

```text
A·A⁻¹ = E
```

</details>

---

## 27. Что такое ранг матрицы?

Сформулируй определение ранга матрицы.

<details>
<summary>Ответ</summary>

<b>Рангом матрицы<b> называется наибольший порядок минора данной матрицы, отличного от нуля.

Обозначения:

```text
r(A)
rang A
```

</details>

---

## 28. Найди ранг матрицы

Определи ранг:

```text
A = | 1  2  3 |
    | 2  4  6 |
    | 0  1  1 |
```

<details>
<summary>Ответ</summary>

Вторая строка зависит от первой:

```text
R₂ = 2R₁
```

Поэтому независимых строк не может быть три.

При этом, например, минор

```text
| 1  2 |
| 0  1 |
```

равен:

```text
1·1 − 2·0 = 1 ≠ 0
```

Значит, существует ненулевой минор второго порядка.

Следовательно:

```text
r(A) = 2
```

</details>

# 🔴 Блок 4. Системы линейных уравнений

## 29. Основная и расширенная матрицы

Для системы

```text
2x + y = 5
3x − 2y = 4
```

запиши:

1. основную матрицу `A`;
2. вектор неизвестных `X`;
3. вектор свободных членов `B`;
4. расширенную матрицу системы.

<details>
<summary>Ответ</summary>

Основная матрица:

```text
A = | 2   1 |
    | 3  -2 |
```

Вектор неизвестных:

```text
X = | x |
    | y |
```

Вектор свободных членов:

```text
B = | 5 |
    | 4 |
```

Расширенная матрица:

```text
(A|B) = | 2   1 | 5 |
        | 3  -2 | 4 |
```

</details>

---

## 30. Совместность системы

Что означает, что система линейных уравнений является совместной?

<details>
<summary>Ответ</summary>

Система называется <b>совместной<b>, если она имеет хотя бы одно решение.

Если решений нет — система называется несовместной.

</details>

---

## 31. Однородная система

Почему однородная система всегда совместна?

<details>
<summary>Ответ</summary>

В однородной системе все свободные члены равны нулю.

Поэтому значения

```text
x₁ = x₂ = ... = xₙ = 0
```

всегда удовлетворяют системе.

Это решение называется <b>нулевым или тривиальным<b>.

</details>

---

## 32. Теорема Кронекера — Капелли

Система линейных уравнений совместна тогда и только тогда, когда:

<details>
<summary>Ответ</summary>

Выполняется условие:

```text
r(A) = r(Ā)
```

где:

- `A` — основная матрица;
- `Ā` — расширенная матрица.

Если ранги различаются, система несовместна.

</details>

---

## 33. Сколько решений может иметь совместная система?

Пусть система содержит `n` неизвестных и является совместной.

Что произойдёт, если

```text
r(A) = n
```

?

<details>
<summary>Ответ</summary>

Если ранг совместной системы равен числу неизвестных:

```text
r(A) = n
```

то система имеет <b>единственное решение<b>.

</details>

---

## 34. А если ранг меньше числа неизвестных?

Пусть система совместна и содержит `n` неизвестных.

Что произойдёт, если

```text
r(A) < n
```

?

<details>
<summary>Ответ</summary>

Система имеет <b>бесчисленное множество решений<b>.

При решении часть неизвестных выбирается как свободные, а остальные выражаются через них.

</details>

---

## 35. Исследуй систему по рангам

Для некоторой системы известно:

```text
r(A) = 2
r(Ā) = 3
```

Совместна ли система?

<details>
<summary>Ответ</summary>

Нет.

По теореме Кронекера — Капелли система совместна тогда и только тогда, когда:

```text
r(A) = r(Ā)
```

Здесь:

```text
2 ≠ 3
```

Следовательно, система <b>несовместна<b>.

</details>

---

## 36. Реши систему методом подстановки

Реши систему:

```text
x + y = 5
2x − y = 4
```

<details>
<summary>Ответ</summary>

Из первого уравнения:

```text
y = 5 − x
```

Подставляем во второе:

```text
2x − (5 − x) = 4
3x − 5 = 4
3x = 9
x = 3
```

Тогда:

```text
y = 5 − 3 = 2
```

Ответ:

```text
x = 3
y = 2
```

</details>

## 37. Формулы Крамера

Для невырожденной системы из двух уравнений

```text
a₁₁x + a₁₂y = b₁
a₂₁x + a₂₂y = b₂
```

что должно быть верно для применения формул Крамера?

<details>
<summary>Ответ</summary>

Определитель основной матрицы системы должен быть ненулевым:

```text
Δ = | a₁₁  a₁₂ |
    | a₂₁  a₂₂ |

Δ ≠ 0
```

Тогда система является невырожденной и имеет единственное решение.

</details>

---

## 38. Реши систему по формулам Крамера

Реши систему:

```text
2x + y = 5
x − y = 1
```

<details>
<summary>Ответ</summary>

Основной определитель:

```text
Δ = | 2   1 |
    | 1  -1 |

Δ = 2·(−1) − 1·1
  = −3
```

Для `x` заменяем первый столбец свободными членами:

```text
Δ₁ = | 5   1 |
     | 1  -1 |

Δ₁ = 5·(−1) − 1·1
   = −6
```

Для `y` заменяем второй столбец:

```text
Δ₂ = | 2  5 |
     | 1  1 |

Δ₂ = 2·1 − 5·1
   = −3
```

Следовательно:

```text
x = Δ₁ / Δ = (−6)/(−3) = 2

y = Δ₂ / Δ = (−3)/(−3) = 1
```

Ответ:

```text
x = 2
y = 1
```

</details>

## 39. Метод Гаусса: первый шаг

Рассмотрим расширенную матрицу системы:

```text
| 1   2  | 5 |
| 2   3  | 8 |
```

Какое элементарное преобразование можно выполнить, чтобы исключить `x` из второй строки?

<details>
<summary>Ответ</summary>

Можно выполнить:

```text
R₂ → R₂ − 2R₁
```

Получим:

```text
| 1   2 | 5 |
| 0  -1 | -2 |
```

Это один из шагов прямого хода метода Гаусса.

</details>

## 42. Полное решение методом Гаусса

Реши систему методом Гаусса:

```text
x + y + z = 6
2x + 3y + z = 10
x + 2y + 2z = 9
```

<details>
<summary>Ответ</summary>

Расширенная матрица:

```text
| 1  1  1 |  6 |
| 2  3  1 | 10 |
| 1  2  2 |  9 |
```

Первый шаг:

```text
R₂ → R₂ − 2R₁
R₃ → R₃ − R₁
```

Получаем:

```text
| 1  1  1 | 6 |
| 0  1 -1 | -2 |
| 0  1  1 | 3 |
```

Теперь:

```text
R₃ → R₃ − R₂
```

Получаем:

```text
| 1  1  1 | 6 |
| 0  1 -1 | -2 |
| 0  0  2 | 5 |
```

Из последнего уравнения:

```text
2z = 5
z = 5/2
```

Из второго:

```text
y − z = −2
y = z − 2
y = 5/2 − 2
y = 1/2
```

Из первого:

```text
x + y + z = 6
x + 1/2 + 5/2 = 6
x + 3 = 6
x = 3
```

Ответ:

```text
x = 3
y = 1/2
z = 5/2
```

</details>

## 43. Комплексная задача

Дана матрица

```text
A = | 1  2 |
    | 2  4 |
```

Ответь сразу на несколько вопросов:

1. Является ли матрица квадратной?
2. Найди `det A`.
3. Является ли она невырожденной?
4. Существует ли `A⁻¹`?
5. Найди `r(A)`.

<details>
<summary>Ответ</summary>

### 1. Квадратная ли матрица?

Да.

Размер:

```text
2 × 2
```

### 2. Определитель

```text
det A = 1·4 − 2·2
      = 4 − 4
      = 0
```

### 3. Невырожденная ли?

Нет.

Так как:

```text
det A = 0
```

матрица является <b>вырожденной<b>.

### 4. Существует ли обратная?

Нет.

Обратная матрица существует только для невырожденной квадратной матрицы:

```text
det A ≠ 0
```

Здесь:

```text
det A = 0
```

### 5. Ранг

Все строки пропорциональны:

```text
R₂ = 2R₁
```

Но матрица не нулевая, поэтому существует ненулевой минор первого порядка.

Следовательно:

```text
r(A) = 1
```

Итог:

```text
det A = 0
матрица вырожденная
A⁻¹ не существует
r(A) = 1
```

</details>

## 44. Комплексная задача на систему

Исследуй систему:

```text
x + 2y = 3
2x + 4y = 6
```

1. Совместна ли система?
2. Определи её ранг.
3. Имеет ли она единственное решение или бесконечно много?
4. Запиши общее решение.

<details>
<summary>Ответ</summary>

Основная матрица:

```text
A = | 1  2 |
    | 2  4 |
```

Вторая строка равна удвоенной первой, поэтому:

```text
r(A) = 1
```

Расширенная матрица:

```text
| 1  2 | 3 |
| 2  4 | 6 |
```

После преобразования:

```text
R₂ → R₂ − 2R₁
```

получаем:

```text
| 1  2 | 3 |
| 0  0 | 0 |
```

Следовательно:

```text
r(A) = r(Ā) = 1
```

Система совместна.

Число неизвестных:

```text
n = 2
```

А ранг:

```text
r = 1 < 2
```

Поэтому решений бесконечно много.

Выразим `x` через `y`:

```text
x + 2y = 3
x = 3 − 2y
```

Пусть:

```text
y = t
```

Тогда:

```text
x = 3 − 2t
y = t
```

Общее решение:

```text
(x, y) = (3 − 2t, t),   t ∈ ℝ
```

</details>

| Блок | Тема                  | Что нужно уметь                                                     |
| ---- | --------------------- | ------------------------------------------------------------------- |
| 0    | Основы                | Размер, элементы, диагональ, виды матриц                            |
| 1    | Операции              | Сложение, умножение на число, транспонирование, произведение        |
| 2    | Определители          | Определители 2×2 и 3×3, свойства, миноры, алгебраические дополнения |
| 3    | Невырожденные матрицы | Обратная матрица, определитель, ранг                                |
| 4    | Системы               | Совместность, ранги, Кронекер–Капелли, Крамер, Гаусс                |

### Условная шкала

- 🟢 <b>Очень хорошо<b> — уверенно решаешь задачи и можешь объяснить, почему решение работает.
- 🟡 <b>Нормально<b> — основные операции выполняются, но отдельные места требуют повторения.
- 🟠 <b>Есть пробелы<b> — правильные ответы получаются не всегда или только с подсказкой.
- 🔴 <b>Стоит вернуться к теории<b> — базовые определения или алгоритмы пока не закрепились.

> Важный момент: если ты получил правильный ответ случайно, но не можешь объяснить ход решения, лучше считать такую тему ещё не закреплённой.
